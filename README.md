
# Pizza Sales Analysis

## 1. Project Overview

This project focuses on analysing pizza sales data using Microsoft Excel and SQL.

The objective is to examine sales performance, identify purchasing patterns, evaluate product performance, and generate meaningful business insights that can support better decision-making.

## 2. Business Problem

The management of a pizza restaurant wants to understand its sales performance and identify opportunities to improve revenue and business operations.

The analysis will investigate sales trends, product preferences, order patterns, and revenue contribution.

## 3. Project Objectives

- Analyse overall sales performance.
- Identify the best-selling and least-selling pizzas.
- Examine revenue generated by different pizza categories.
- Analyse sales trends across days, months, and hours.
- Identify popular pizza sizes.
- Calculate important business performance indicators.
- Provide data-driven recommendations.

## 4. Tools and Technologies

- Microsoft Excel
- SQL

## 5. Dataset

The project uses a pizza sales dataset containing transactional sales records.

Dataset filename: pizza_sales.csv

## 6. Project Methodology

The project will follow these stages:

1. Data inspection and understanding.
2. Data cleaning and preparation.
3. Exploratory data analysis using Excel.
4. SQL-based data analysis.
5. Data visualisation.
6. Interpretation of findings.
7. Business recommendations.

## 7. Key Performance Indicators (KPIs)

The following metrics will be investigated:

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order
